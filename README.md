 Project ini berfokus pada analisis performa jaringan seluler menggunakan dataset yang berisi metrik kualitas jaringan, seperti kekuatan sinyal, latensi, kecepatan unduh dan unggah, serta jenis teknologi jaringan (3G, 4G, dan 5G). Data diproses menggunakan SQL untuk melakukan data cleaning, transformasi, dan analisis, kemudian divisualisasikan dalam dashboard interaktif menggunakan Tableau. Dashboard ini dirancang untuk membantu memantau performa jaringan, mengidentifikasi tren kualitas layanan, serta memberikan insight yang dapat mendukung evaluasi dan pengambilan keputusan berbasis data.
Tools : MySQL, Tableau

Dataset : https://www.kaggle.com/datasets/suraj520/cellular-network-analysis-dataset
